## Overview

> A structured, continuously growing archive of my Data Structures and Algorithms practice — every accepted submission on LeetCode lands here automatically, no manual copy-pasting involved.

This repository doubles as a **problem-solving log** and an **interview-prep reference**, spanning arrays, strings, linked lists, trees, graphs, dynamic programming, greedy strategies, backtracking, and more. Each solution is committed the moment it's accepted, so the commit history itself becomes a timeline of progress.

**Core focus areas:** `Arrays` · `Strings` · `Linked Lists` · `Trees` · `Graphs` · `Dynamic Programming` · `Greedy` · `Backtracking` · `Binary Search` · `Two Pointers` · `Sliding Window` · `Heaps` · `Tries`

<br/>

## How the Sync Works

| Step | Action |
|:---:|:---|
| `01` | Solve a problem on LeetCode |
| `02` | Submission gets **Accepted** |
| `03` | [LeetSync](https://github.com/rte6/LeetSync) extension detects the accepted run |
| `04` | Code, problem statement, and metadata are auto-committed here |
| `05` | Repository structure updates — folder-per-problem, zero manual effort |

No stale solutions, no forgotten uploads — if it's solved, it's already here.
